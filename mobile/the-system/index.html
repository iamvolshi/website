ARCHE — the Adaptive Relational Cognitive Human Emulator. The architecture doesn't store intelligence and bolt memory on afterward. It emulates how humans function — interaction, behavior, and memory as one design. The engines run on ARCHE. The personas are built on it.

SUBSTRATE TAXONOMY

Memory isn't a feature. It's the substrate.

The tritemporal work underneath — event time, tick time, knowledge time — runs on TEMPE, the time engine.

01 Input

The world arrives as events — interactions, observations, handoffs. Everything the system will ever know starts here.

02 Attention

Not every event matters equally. ARCHE decides what deserves weight — what to record deeply, what to let pass. Attention is the first act of memory.

03 Record

What attention keeps is recorded with its authority and its moment — bound by KATIE, retrievable by ERIE, learned from by ELLE.

ELLE EXTERNAL LEARNING LOOP ENGINE
FORGE
in the forge — engine rebuild underway

Every interaction is an experience, and experience accumulates: lessons learned, scoped, attributed — durable rules that survive model replacement and follow the user into whatever model they talk to next.

01 EXPERIENCE Every interaction with the user — lived, not logged. What happened, in context.
02 LESSON Experience distills into a lesson: what was learned, scoped to where it holds, attributed to its source.
03 RULE Lessons mature into rules — durable, portable, surviving whatever model comes next.
04 RETURN The rules follow the user into every future interaction. Never start from zero again.
WHY EXTERNAL?

Models get replaced. Fine-tuning gets wiped. Context windows get flushed. ELLE's loop is external — the lessons live outside any single model, so the user's accumulated experience survives all of it. Swap the model underneath; the learning stays.
