Her job

Experience in. Lessons out.

ERIE answers what do I know, and why. ELLE answers what did I learn, and why. She watches the experience she's having with the user — what worked, what failed, what the user corrected — and turns it into durable learning: maturation into rules, scoped to where they apply, attributed to the experience they came from.

01

Experience

Every interaction with the user — lived, not logged. What happened, in context.

02

Lesson

Experience distills into a lesson: what was learned, scoped to where it holds, attributed to its source.

03

Rule

Lessons mature into rules — durable, portable, surviving whatever model comes next.

04

Return

The rules follow the user into every future interaction. Never start from zero again.

Why external

The learning doesn't live inside the model.

Models get replaced. Fine-tuning gets wiped. Context windows get flushed. ELLE's loop is external — the lessons live outside any single model, so the user's accumulated experience survives all of it. Swap the model underneath; the learning stays.

01

Scoped

Every lesson knows where it applies — a lesson about one user doesn't leak into another.

02

Attributed

Every lesson carries where it came from — the experience it was learned in, on the record.

03

Durable

Lessons outlive models. Replacement, retraining, new vendor — the loop doesn't care.
